## twitter-archive 工具（Wayback Machine CDX 查询）

- 在 twitter-archive/ 下实现了 Python CLI：main.py / cdx_client.py / archive_fetcher.py / tweet_parser.py / exporter.py，requests + argparse + pathlib + logging，Retry（429/500/502/503/504 指数退避）+ resumeKey 分页。
- Cyber_Sudo 实测结果：4 个 URL 模式共 17 条 CDX 记录 → 6 条唯一推文、7 个历史快照，6 个快照验证全部 200 text/html；最早存档 2022-03-01，最晚 2026-02-07。
- 关键环境问题：本机无法直连 archive.org，沙箱代理（127.0.0.1:56221）对 web.archive.org 返回 502；必须走系统代理 127.0.0.1:7897。给 main.py 加了 --proxy 参数（设置后 trust_env=False 忽略环境代理）。后续跑网络请求需 dangerouslyDisableSandbox + --proxy http://127.0.0.1:7897。
- 数据很少的原因：该账号存档本来就少；/status/ 之外多为页面级存档，被 tweet_parser 排除（17 条中 10 条非推文）。

## 第一阶段：推文状态检测 + 媒体展示

- 新增 x_status_checker.py（Syndication tweet-result 检测，token 按 react-tweet 算法 ((id/1e6)^floor(id%2075653)).toString(16) 动态计算，404/403/429 不判删除）、media_extractor.py（photo ?name=orig 原图、video 最高 bitrate MP4、animated_gif）、local_server.py（纯标准库 ThreadingHTTPServer，/api/data、/api/inspect 后台线程+轮询进度、原子保存）、static/（原生 HTML/CSS/JS 调试页，Debug Preview 零外部请求）。
- Cyber_Sudo 6 条真实检测结果：3 active / 3 deleted / 0 unavailable / 0 unknown，Syndication 成功率 6/6。关键发现：已删除推文返回 HTTP 200 + Tombstone JSON（"This Post was deleted by the..."），而非 404 —— 验证了"200≠存在、404≠删除"的设计。2 条 active 推文带 photo（pbs.twimg.com ?name=orig）。
- 检测 X 需走系统代理 127.0.0.1:7897（本机直连 X/Syndication 不通）。
